# template

このディレクトリには、`#include` してそのまま使う完成ライブラリではなく、
問題ごとにコピーして書き換えて使う実装テンプレートを置く。

各ファイルの先頭には、例えば

```cpp
// template/segtree/prefix_state.hpp
```

のようにファイルパスをコメントとして記述する。
テンプレートを提出コードへコピーした場合も、このコメントは残す。
maspy-cp-log ではこのコメントを利用して、各テンプレートの使用例を検索・索引化できるようにする。
通常のライブラリと異なり、テンプレート本体は問題ごとに変更して使うことを前提とするため、
個々のファイルについて通常の verify 行わない。
